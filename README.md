How to Use the System

1. Run `Main.java` in IntelliJ IDEA.

2. Choose an option from the Main Menu:

1 – Sales Recording
2 – Credit Ledger
3 – Exit

Sales Recording

1. Enter the customer's name.
2. Enter the product name.
3. Enter the product price.
4. Enter the quantity.
5. Enter the customer's payment.
6. The system will calculate the total and display the change or remaining credit.
7. Press **Enter** to return to the Main Menu.

Credit Ledger

1. Select **Credit Ledger** from the Main Menu.
2. The system will display the customer's current credit.
3. Enter the customer's payment.
4. The system will update the remaining credit.
5. The system will display **PAID** if the credit is fully paid or **UNPAID** if there is still a balance.
6. Press **Enter** to return to the Main Menu.

To Exit

Select **3 – Exit** from the Main Menu.
